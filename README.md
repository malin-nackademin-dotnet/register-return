# Register return

A simple console application built with C# and .NET to test the flow of an activity diagram and a sequence diagram that describes how to register a return.

## Technologies

- C#
- .NET

## Project Structure
The project uses a simple folder structure to organize the code:
```bash
register-return/
└── RegisterReturnConsoleApp/
    ├── Interfaces/
    ├── Models/
    ├── Services/
    ├── Repositories/
    └── Program.cs
```
## Getting Started

### Prerequisites

- .NET SDK

### Run the Application

Clone the repository:
```bash
git clone <repository-url>
```
Navigate to the project directory:
```bash
cd <project-folder>
```
Run the application:
```bash
dotnet run
```
